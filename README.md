# javafx-authentication-demo

JavaFX desktop app with PF4J plugins demonstrating OIDC login that keeps working when the IdP is unreachable.

See [docs/PLAN.md](docs/PLAN.md) for the phased plan.

Stack: JDK 21, Maven, JavaFX, SnapFX, PF4J.
